Adminbereich öffnen?

Dieser Bereich ist ausschließlich für Wartung und Administration vorgesehen.

Hier können Streams gestoppt, Raspberry Pis neu gestartet oder heruntergefahren, Software-Updates ausgeführt und Dateisystem-Schutzmechanismen verändert werden.

Fehlerhafte Bedienung kann die Installation unterbrechen oder einen Raspberry Pi während einer Wartung vorübergehend beschreibbar lassen.
